🛒 E-Commerce SQL Data Analysis

This project focuses on analyzing e-commerce product data using PostgreSQL.
The goal is to explore the dataset, clean the data, and answer useful business questions using SQL.

📌 Project Overview

The analysis covers:

Data exploration and basic statistics
Handling missing and incorrect data
Price conversion from paise to rupees
Product and category analysis
Discount and pricing analysis
Inventory analysis
Revenue estimation
🧹 Data Cleaning

The following cleaning steps were performed:

Checked for NULL values
Removed products with MRP = 0
Converted prices from paise to rupees
Checked duplicate product names
📊 Business Questions Answered

Using SQL, the project answers questions such as:

What are the top 10 products with the highest discounts?
Which high-MRP products are out of stock?
What is the estimated revenue for each category?
Which products have MRP above ₹500 and discounts below 10%?
Which top 5 categories offer the highest average discount?
Which products provide the best price per gram?
How can products be grouped into Low, Medium, and Bulk based on weight?
What is the total inventory weight for each category?
